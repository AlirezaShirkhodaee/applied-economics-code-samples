# Task: Cognitive constraints in LLM "silicon samples"

*Originally a timed data task. The research question and data requirements are reproduced below.*

## Research question

How well can the effect of cognitive constraints on choice behavior be replicated using "silicon samples" of LLM agents instructed to simulate humans?

## Task

1. Select one (or several) concrete economic choice contexts in which cognitive constraints have been argued to affect choice behavior. Cognitive constraints are limits in human information processing, such as limited attention, limited memory, or limited computational power. A result of cognitive constraints can be confusion, or "cognitive uncertainty."

   Examine whether and how well (some) human choice patterns attributed to cognitive constraints can be replicated in experiments where the experimental subjects are not humans but LLM agents. This means running synthetic experiments.

2. Use the Expected Parrot (`edsl`) open-source Python package, with remote inference for all simulations. The `remote_inference_cost()` method reports the simulation cost of an experiment before it is run.

## Data

There is no external data set: the data are generated by the synthetic experiments themselves.

## Guidance

- The challenge is deliberately open-ended and requires putting structure on a difficult task.
- The notebook should focus on generating, documenting and analyzing the best evidence, not on recording everything that was tried.
- A human experiment does not have to be mimicked narrowly; the new possibilities of LLM agents (for example measuring constructs or inducing constraints) can be used.
- Small-sample, proof-of-concept experiments are fine; statistical significance is not the focus.
