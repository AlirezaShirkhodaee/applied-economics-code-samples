# Data

The data set `auctions.csv` is **not publicly available** through this repository. It was supplied with the task and contains the experimental first-price auction data of Dyer, Kagel and Levin (1989) as used by Bajari and Hortaçsu (2005).

To run the notebook, place `auctions.csv` in this folder. The code expects the columns `Experiment`, `Value`, `BidC3` and `BidC6`.
